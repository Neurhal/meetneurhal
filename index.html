Request a study brief, artifact review, grant alignment discussion, bounded workflow evaluation, or runtime assurance collaboration. The form prepares an email draft with enough context to route the inquiry by study fit, artifact maturity, partner type, and evaluation focus.

Security and privacy disclosure

This website is a static public site. The contact form does not submit to a NeurHAL server, set cookies, use analytics, call a remote form endpoint, or store inquiry data in browser storage.

When you select Open study inquiry draft, the page creates a mailto draft in your email client using the fields you entered. You can review, edit, or discard that draft before sending. Email delivery, retention, scanning, and metadata are then handled by your email provider, any intermediate mail systems, and the receiving mailbox.

  • Do not include passwords, API keys, private keys, tokens, seed phrases, credentials, or production secrets.
  • Do not include exploit code, live vulnerability details, customer records, regulated data, export-controlled material, or confidential architecture diagrams in the initial inquiry.
  • Use the form for high-level routing only: organization, role, inquiry focus, and a brief non-sensitive summary.
  • Detailed materials should move through an agreed review channel with appropriate authorization, confidentiality terms, and handling expectations.

Normal hosting infrastructure may still receive ordinary request metadata when this page is loaded. Once an email is sent, message handling moves outside the website's control.
